## Contributing

1. Dump links (or a short list) in chat / issue for the Launchpad team.
2. Add items in the matching category as:
   `- [Title](https://example.com) - One-line description.`
3. Open a PR against `main`. Prefer one category per PR when the batch is large.
4. Do not invent entries — only add sources you have verified.

Weekly rhythm: Bei (or the team) dumps candidate links → someone opens a PR against this repo → merge to `main`.
